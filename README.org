#+TITLE: lunixose website
#+AUTHOR: lunixose
#+DATE: 2026-08-10

Personal dashboard + blog, self-hosted on the oracle VPS.

- Dashboard: status cards for self-hosted services (Forgejo, Syncthing,
  Email).
- Blog: public Emacs org notes (=#+public: t=) from ~/root/Notes~, read
  live from the server and rendered in the browser.

Live: https://lunixose.duckdns.org/

* Stack

- React 19 + TypeScript + Vite
- Tailwind v4 with ~@catppuccin/tailwindcss~ (Catppuccin Mocha)
- uniorg (org parser, client-side rendering)
- h3 (Node server: static files + =/api= endpoints)
- Built + deployed via Nix (flake) to a NixOS systemd service

* Run locally (dev)

#+begin_src bash
npm install
npm run dev            # frontend on :5173 (proxies /api → :3100)
npm run dev:server     # API server on :3100
#+end_src

Type-check / build:

#+begin_src bash
npm run typecheck
npm run build          # dist/ (web) + dist-server/index.mjs (server)
npm run preview        # production preview on :3100
#+end_src

* Deploy (Nix)

The flake builds the site:

#+begin_src bash
nix build .#default    # output: result/share/lunatix-website/
#+end_src

The lunatix NixOS config pulls this repo as a flake input
(~modules/community/server/website.nix~) and runs it as a systemd
service:

- ExecStart: node <pkg>/share/lunatix-website/index.mjs
- PORT 3100, user www-data
- NOTES_DIR=/root/Notes

To deploy changes:

1. Commit + push this repo
2. In ~Proj/lunatix~: ~nix flake lock --update-input website~
3. Commit + push lunatix
4. On oracle: ~nixos-rebuild switch --flake github:quocjq/lunatix#oracle --refresh --no-write-lock-file~

* API

- GET  /api/services/:name   → {status, message} for forgejo/syncthing/mail
- GET  /api/notes            → public note list (metadata)
- GET  /api/notes/:id        → raw org content
- GET  /rss.xml              → RSS feed of public notes

* Troubleshooting

- npmDepsHash mismatch in nix: set lib.fakeHash, build, copy the "got:"
  hash back into nix/package.nix.
- Nix build missing src/: git-add the file first (cleanSourceWith filters
  by git tracking).
