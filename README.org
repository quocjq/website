#+TITLE: Lunatix Website
#+AUTHOR: lunixose
#+DATE: 2026-08-09

Notion-like personal dashboard / editor, self-hosted on the oracle VPS.
A Nuxt 4 app with a TipTap editor (Vim mode), a left sidebar (Forgejo,
Pi-hole, Email, Syncthing), local document storage, and password auth.

Live: https://lunixose.duckdns.org/

* Stack

- Nuxt 4 (Vue 3, Nitro server)
- @nuxt/ui v4 (UI layer — toolbar, buttons, sidebar)
- TipTap v3 (editor) + vim-prosemirror (Vim keybindings)
- yjs (document model, unused collab currently)
- nuxt-csurf (CSRF protection)
- Persistence: JSON docs on disk (DOCS_DIR)
- Built + deployed via Nix (flake) to a NixOS systemd service

* Run locally (dev)

#+begin_src bash
npm install
npm run dev            # http://localhost:3000
#+end_src

Dev env vars (defaults fine for local):
- DOCS_DIR — where docs are stored (default ./.data/docs)
- ADMIN_PASSWORD or ADMIN_PASSWORD_FILE — admin login (default "changeme")

Type-check / build:

#+begin_src bash
npm run typecheck
npm run build
node .output/server/index.mjs   # production preview
#+end_src

* Deploy (Nix)

The flake builds the SSR bundle:

#+begin_src bash
nix build .#default            # output: result/share/lunatix-website/.output/
#+end_src

The lunatix NixOS config pulls this repo as a flake input
(~modules/community/lix/services/website.nix~) and runs it as a systemd
service:

- ExecStart: node <pkg>/share/lunatix-website/.output/server/index.mjs
- PORT 3100, user www-data
- DOCS_DIR=/srv/www/data/docs
- ADMIN_PASSWORD_FILE=/run/website/admin-password (agenix secret)

To deploy changes:

1. Commit + push this repo
2. In ~Proj/lunatix~: ~nix flake lock --update-input website~
3. Commit + push lunatix
4. On oracle: ~nixos-rebuild switch --flake github:quocjq/lunatix#oracle --refresh --no-write-lock-file~

* Using the site

- Guest: opens the shared "welcome" doc (editable, read-only for create/delete).
- Admin: click login in sidebar, enter the admin password (agenix secret
  ~website-admin-password~) → can create/delete docs.
- Vim mode: toggle in the header; status shows -- NORMAL -- / -- INSERT --.
- Sidebar apps:
  - Forgejo: https://git.lunixose.duckdns.org/
  - Pi-hole: https://dns.lunixose.duckdns.org/
  - Email / Syncthing: placeholders (backends TBD)

* Auth model

Single shared password (no accounts). Cookie is HMAC-signed
(server/utils/auth.ts). CSRF via nuxt-csurf — browser requests use
$csrfFetch (see useAuth.ts / useDocs.ts). The password comes from
ADMIN_PASSWORD_FILE if set, else ADMIN_PASSWORD, else "changeme".

* Docs API

- GET  /api/docs              → [{id, title, updatedAt}]
- GET  /api/docs/:id          → {id, title, updatedAt, content}
- POST /api/docs              → create {id, title, content}
- PUT  /api/docs/:id          → save {content} (title derived from text)
- DELETE /api/docs/:id

:id must match [a-z0-9-]+ (path traversal guarded in server/utils/docs.ts).

* Troubleshooting

- Build fails on Google-fonts fetch: harmless warning offline; real errors
  are the [error] lines.
- npmDepsHash mismatch in nix: set lib.fakeHash, build, copy the "got:"
  hash back into nix/package.nix.
- Nix build missing app/: git-add the file first (cleanSourceWith filters
  by git tracking).
- 403 on /api/auth from curl: that is CSRF working; use the browser or a
  csrf token.
